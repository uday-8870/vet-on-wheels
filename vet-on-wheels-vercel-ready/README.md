# Vet on Wheels

Interactive Next.js prototype for a mobile veterinary service in Hyderabad.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy to Vercel

1. Upload every file and folder in this package to the root of your GitHub repository.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Keep **Framework Preset** set to **Next.js** and **Root Directory** set to `./`.
4. Leave Build Command and Output Directory on their automatic defaults.
5. Select **Deploy**.

The application is a prototype. Payments, live tracking, clinical diagnosis and support messaging are simulated.
